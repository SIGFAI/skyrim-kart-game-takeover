# Kart Game Takeover

**Skyrim** × Kart Game · visual · idea by the team

Bring Kart Game into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Riverwood into a kart race: fox, elk, chicken and goat rivals, homing shells, banana peels. Cluck Norris drives a purple kart.

## Install

Copy the release folder contents (Sigf.esp plus Scripts, Meshes, Textures) into Skyrim Special Edition's Data folder, enable Sigf.esp, and load a game near Riverwood. The kart race starts by itself a few seconds after loading.
